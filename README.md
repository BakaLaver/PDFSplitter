# PDFSplitter

**PDFSplitter** — это десктопное приложение с графическим интерфейсом для безопасной работы с PDF-документами. Инструмент позволяет извлекать отдельные страницы из файлов и объединять несколько документов, не отправляя их в облако или на сторонние серверы.

## Зачем это нужно

Безопасное извлечение страниц из личных документов (паспортов, договоров, выписок) без загрузки в интернет. Все данные остаются на вашем компьютере.

PDFSplitter работает полностью на вашем компьютере. Все операции выполняются локально, что гарантирует полную конфиденциальность.

## Функциональность

Приложение разделено на два независимых блока: извлечение страниц и объединение документов.

### 1. Извлечение страниц

Позволяет вырезать одну или несколько страниц из исходного PDF и сохранить их в отдельный файл.


**Параметры:**
* **Файл:** Исходный PDF-документ. Вы можете указать путь к нему через кнопку обзора (`...`) или просто перетащить файл в поле ввода.
* **Имя нового файла:** Название для результирующего документа. Расширение `.pdf` будет добавлено автоматически. Рекомендуется использовать только буквы, цифры и дефисы (избегайте спецсимволов и точки в имени).
* **Сохранить в папку:** Директория для сохранения результата. Выбирается через диалоговое окно кнопкой "Выбор папки".
* **Диапазон страниц (От - До):** Номера страниц, которые необходимо извлечь. Нумерация начинается с 1. Для извлечения одной страницы укажите одинаковые номера в обоих полях.

После заполнения всех полей нажмите **"Извлечь"**. При успешном завершении появится уведомление с предложением открыть папку с готовым файлом.



### 2. Объединение документов

Позволяет склеить два PDF-файла в один. Страницы первого документа будут в начале итогового файла, за ними последуют страницы второго.



**Параметры:**
* **Первый документ / Второй документ:** Пути к исходным PDF-файлам. Выбор файла также поддерживает функцию drag-and-drop.
* **Имя нового документа:** Название для объединенного файла. Расширение `.pdf` будет добавлено автоматически.
* **Сохранить в папку:** Директория для сохранения результата.

Заполните все поля и нажмите **"Объединить"**. После завершения операции вы увидите соответствующее уведомление.


## Технические особенности

* Полностью локальная работа: никаких загрузок на сторонние сервера.
* Интуитивный графический интерфейс с поддержкой drag-and-drop для файлов.
* Автоматическое добавление расширения `.pdf` к именам сохраняемых файлов.
